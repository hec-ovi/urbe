# CONTRACT: coordinator

Purpose: starts the sibling toolkits and verifies their local integration.

Status: 0.10.

## In

- Sibling checkouts and their public contracts: [docs/INDEX.md](docs/INDEX.md).
- Service, volume and port definitions: [docker-compose.yml](docker-compose.yml).
- `BOX_UID` and `BOX_GID` select file ownership, default 1000. `BOX_OFFLINE_INSTALL=1` restricts changed-lock dependency installs to npm's existing cache and disables lifecycle scripts. Normal installs use the lockfile with lifecycle scripts enabled. npm update notifications are disabled.
- `URBE_MODELS_DIR` selects the existing character asset tree. Compose downloads no game assets.
- `LLM_BASE_URL` (default the host's port 8080), `LLM_MODEL` and `LLM_API_KEY` reach Engine for NPC dialog, city names and written stories, and Quests for story authoring; `LLM_TIMEOUT_MS` reaches Engine. `VOICE_BASE_URL` (default `http://voice:8080`) points Engine at Voice.
- `COMPOSE_PROFILES=voice` in `.env` ([.env.example](.env.example)) starts the voice services with the stack. `URBE_GGUF_DIR` (default `~/models/gguf`) holds the voice model `URBE_VOICE_MODEL` (default `maya1/maya1-q4_k_m.gguf`). `RENDER_GID` and `VIDEO_GID` (default 990 and 44) give the voice model `/dev/dri`. `VOICE_CACHE_MAX_MB` and `VOICE_ACCENTS` reach Voice.

## Out

- Twelve Compose services; `voice-model` and `voice` run only under the `voice` profile. Nine bind loopback ports 5301 through 5309: Atlas 5301 (`npm run preview`), Connections 5302 (`npm run dev`), Exterior 5303 (`npm run preview`), Interior 5304 (`npm run preview`), Simulation 5305 (`npm run testbed`, page `/testbed/`), Engine 5306 (`npm run play`), Materials 5307 (`npm run preview`), Voice 5308 (`/health`), voice model 5309 (llama.cpp, `/health`). Streets typechecks then idles with no public port. Quests builds then watches with no public port. Naming builds then idles with no public port.
- The voice model is llama.cpp's Vulkan server, build b11176, with one slot and a 4096-token context on the GPU. Voice is built from its box, starts once the model is healthy and keeps its audio cache in the `voice_data` volume. Engine starts without either.
- Sibling data mounted read-only, generated worlds in Engine's ignored output directory. Engine serves its launcher in stable play mode; source changes apply on restart. Starting the stack preserves the catalog and creates no world. The shared npm cache is a persistent Docker volume.
- Streets becomes healthy before Engine starts. Engine reads Streets, its own source and installed dependencies, and the native Materials schema in-process.
- Naming and Quests become healthy before Engine starts. Engine reads both with their installed dependencies read-only and runs their CLIs in place: Naming's `npm run world` names a themed city before it is built, and Quests' `npm run author` writes a story against the opened interiors.
- Interior builds its portable feasibility entry before its preview starts. Exterior waits for that preview and reads the same compiled entry as native Node.
- Atlas proxies exterior capability and job requests to Engine through the Compose service address `http://engine:5306`. Engine permits that hostname explicitly; browser viewer links use the public loopback address. Engine can be unavailable without preventing Atlas inspection.
- Atlas hosts its blueprint-generation API on its preview port. City worker startup follows Atlas's package contract; the ignored `.atlas-cities` catalog persists through the writable checkout mount. Exterior and interior stages remain explicit.
- `compose/check-boxes.sh` builds Interior's feasibility entry, then runs tests and production builds for atlas, connections, exterior, interior, materials, naming, quests, simulation and engine, then Voice's Docker `test` stage.
- `compose/check-previews.sh` verifies served pages, material data, street bindings, exterior API parity and every ready catalog world.
- `node compose/check-catalog.mjs [baseUrl]` checks the current catalog, exact blueprint/Connections hashes, every archive part and served building files without mutation: a kit parcel's placement record, a generated shell's blueprint and GLB, an opened interior's building, NPC and layout documents; an empty lot is named only in `sources`. Default `http://localhost:5306`.
- `node compose/check-voice.mjs [baseUrl]` checks Voice health, streams one fresh line and requires a PCM16 mono 24 kHz RIFF header, first audio under 2 s, a real-time factor under 1.5 and a cached replay. Each run leaves its line in the bounded cache. Default `http://localhost:5308`; when nothing answers it prints a skip line and exits 0.
- The launcher checks share [compose/launcher.mjs](compose/launcher.mjs): node:http with no request timeout, short calls on `POST /api/launcher`, and each creation stage as an Engine creation job read every two seconds until it settles.
- `node compose/check-launcher.mjs [small|medium|large] [baseUrl]` creates a fresh template city and free-play game, checks served shell files, then saves and resumes through the launcher API. Defaults: small and `http://localhost:5306`. Template sizes: Small 500 m, Medium 1000 m, Big 3000 m. Generated check cities and games remain in Engine's ignored catalog.
- `node compose/check-story.mjs <cityId> [baseUrl] [interiors] [sideJobs]` opens interiors on an existing city, selects the recorded story and makes a game of it, printing the play URL. Defaults: `http://localhost:5306`, 7 and 2.
- `node compose/check-game.mjs <small|medium|large> [baseUrl] --theme "<city character>" --brief "<story premise>" [--interiors 9] [--side-jobs 3]` makes one story game through the model server: a city named in the theme (named manifest, its theme, NPC types), interiors including a home, a story written against them (at least six main steps, a recording naming its model) and the game. It checks that the shipped bundle's files hold what its manifest counts, every quest record names a shipped quest, every place and scene is an opened interior, the game declares scenery and ships no story, handoff input or unselected definitions, then prints each stage's seconds and the play URL. A Small city takes minutes; the story stage takes most of the time.
- `node compose/play-probe.mjs <world id | play url> [talk] [chat] [voice] [follow] [lead] [scene]` plays scenarios through Engine's [automation probe](engine/src/game/debug/CONTRACT.md) in a headless Chromium-family browser (`--browser`, `URBE_BROWSER`, else Brave, Chrome or Chromium on PATH), with no dependencies. It opens the world's `out` preview (a `game=` URL becomes one) with `&automation`, WebGL at low quality and a crowd of 120, and never saves. GET and HEAD requests pass, `/api/talk` and `/api/talk/stream` get a stand-in reply in the browser, and every other request is refused; the page's Vite socket stays closed. Each talk request is recorded with the place (`guide`) and offers it carried. `--talk live` lets talk reach the model, and the engine then keeps each exchange in that world's dialogue memory until it restarts, so on a game's out (`/out/games`) it also needs `--throwaway-engine`. The browser runs on the probe's DevTools pipe and quits when the probe ends, however it ends; SIGINT, SIGTERM and SIGHUP write the report first. `talk` walks up to each of the six nearest people it can reach in turn, needing three, presses E, leaves by the chat's leave button, and checks that each keeps their crowd body, outfit, hair and eyebrows through the talk and after it; `chat` checks that a line reaches `/api/talk` and a reply shows; `voice` speaks a person's first line and a chat reply through Engine's `/api/voice` with page audio muted, judges the first line by its first `POST /api/voice`, checks that every `POST /api/voice/prefetch` answered 202, and needs the Voice box running behind the engine (voice requests, the `DELETE /api/voice/prefetch/<group>` cancel included, pass through to it); `follow` asks the nearest people with the chat's 'Come with me' until one comes along, stands 12 to 20 m away on the pavement, checks that the follower closes to 2.5 m and waits, then lets them go with 'You can go now' and checks that they go back to their day; `lead` asks for the nearest place someone offers to show within 300 m, walks 2.5 m behind them on their own path, and checks that the way shrinks, the leader arrives, the talk about the place opens by itself with the place in its request and the leader speaking first, and that leaving it sends them back to their day; `scene` checks that no quest scene failed, stands the player at the edge of each scene the preview stages at quest start (or the one `--scene <id>` names), and checks that it stands around them with every body, prop and decal drawn, with a screenshot each; the preview starts its quests fresh, so a scene a later step stages stays dormant there and the report lists it as not visited, and a game with no scenery, or none staged at quest start, gives it nothing to play. Screenshots and `report.json` (checks, talk requests, console errors) go to `--out`, default a new folder under the OS temp dir, never inside this checkout. Exit 0 when every scenario passes or has nothing to play, 1 when a check fails or a scenario errors, 2 when the game never plays, 128 plus the signal number when stopped. Default base `http://localhost:5306`.
- `node compose/shoot.mjs <play url> <out dir> <shots.json>` writes one PNG per shot of a running game, with no window: it waits for the world to be on screen, then walks the camera through the shots (`{ name, pos, yaw, pitch, wait }`). Add `&backend=webgl&quality=low` to the URL; headless Chromium cannot compile the city's WebGPU pipelines. Playwright resolves from this checkout, or from the checkout `URBE_PLAYWRIGHT` names (a folder with `node_modules`).

## Errors and invariants

- Commands retain the failing installer, build, test or service's nonzero exit status. Missing offline cache entries fail startup.
- Dependency installation runs only when the lockfile hash differs; its recorded hash changes only after a successful install.
- Preview ports bind to loopback. This coordinator defines no city geometry or material recipes.
