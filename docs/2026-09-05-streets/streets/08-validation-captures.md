# 08. Validation captures

Status: drafted.

## Capture protocol

Record seed, exported parameters, renderer, quality, camera, and source geometry identifiers. Capture the same case from overhead, street level, close boundary, and walking views.

Run intended night lighting and neutral diagnostic lighting when investigating materials. Store implementation evidence next to the subsection that owns the result.

## Evidence states

- unreviewed: exact source exists;
- mapped: linked to a subsection;
- reproduced: current output matches the capture setup;
- accepted: relevant checks pass;
- blocked: a named dependency prevents comparison.

The exact supplied files are listed in [section references](section_references/INDEX.md).
